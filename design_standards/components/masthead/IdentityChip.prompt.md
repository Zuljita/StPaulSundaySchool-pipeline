Solid navy chip naming the level and document type; the one element a volunteer scans for in a stack of sheets.

```jsx
<IdentityChip>Primary 1–2 · Student Handout</IdentityChip>
<IdentityChip size="small">Nursery Notes · Birth–3</IdentityChip>
```

Always both facts, in that order, separated by a middot. Never a bare level name. Use `small` in running headers only.

Twelve pieces, one Gospel, one look every week. Everything on these three pages is set in the system it describes.

Page Geometry

Letter portrait, one .page per printed sheet. The page box is exactly 816 × 1056 px. Content that misses it is clipped, not reflowed.

Margins 0.4in top, 0.55in sides, 0.34in foot. Lesson pages may tighten to 0.34 / 0.55 / 0.3.

The two-column frame

Nearly every piece is a 1 : 2.05 grid, 26px gutter, hairline rule between: a reference rail on the left, the week's substance on the right.

Footer Pinning

The inner wrapper is a full-height flex column; the footer takes margin-top: auto. Every other direct child takes flex: none, or a squeezed multi-column block spills sideways off the sheet.

Print Reality

Color laser, double-sided, background graphics on. Body ink is near-black, never navy: navy at body size prints visibly blue.

Palette

Sampled from the church logo. Two blues carry the identity; red is reserved for two jobs only. No color is decorative.

Skeletons and rules

Three Skeletons

Any new handout is one of these three. A new level changes the chip and the Level Question, never the layout.

Teacher’s Guide · 3pp

Page 1 prep: rail of What You Need, Time Today, The Text, This Week in the Room, against For the Teacher, Law and Gospel, Memory Work. Page 2 the Gospel in full plus What Children Ask (Discussion Guardrails for the older rooms) beside the Catechism. Page 3 The Lesson, every text inline.

Student Handout · 1–2pp

Rail of hymn stanza, Catechism, the Collect, then the artwork panel. Main column the Gospel in full, the navy Memory Work panel, then the week’s activities side by side over ruled lines. One page is the default; take a second page rather than crowd the sheet.

Family Take-Home · 2pp

No rail. Page 1 runs the Theme Line beside the week’s verse, the same-Gospel paragraph, all six Level Questions in a bounded band, then What They Heard in two flowing columns. Page 2 is A Word for the Parents over a three-column band of the week’s helps.

Standing Rules

The content is verbatim. Format it; never rewrite, tighten, or paraphrase what the week supplies.

Levels differ by name, never by layout. Same skeleton, same rail, same order of blocks, whatever the age of the room.

A teacher never hunts for a text. Every prayer, stanza, recitation, verse and benediction prints inline at the step where it is spoken, even when that means printing it twice in one document.

Nothing internal reaches a volunteer’s sheet. No specification references, no production notes, no editorial apparatus.

Body ink is never navy. Navy is for display type, chips, and solid panels only.

Nothing a room does not do. A level without a Catechism Recitation carries no sidebar sentence promising one.

Before It Prints

Every page must report zero overflow. The page box clips; it does not reflow, so a page that runs long loses its footer silently.

When a page runs long, trim in this order

Sidebar gaps, then body size by 0.5px, then the artwork panel, then move a whole block to the page with room. Never take the Gospel below 12px.

Export per file, or the whole 24-page set from the weekly packet. Scale 100%, margins default, background graphics on.

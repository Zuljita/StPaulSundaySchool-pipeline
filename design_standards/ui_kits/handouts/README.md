# Handout kit

One complete printed sheet — a Primary student handout — built entirely from the tokens in
`styles.css`. It is the starting point for any new student handout: replace the content, leave
the frame alone.

`index.html` is also registered as a Starting Point, so a consuming project can seed a new
design from it directly.

## The three skeletons

Any new piece is one of these. The live production files live at the project root as
`.dc.html` documents; this kit is the token-driven reference copy.

| Skeleton | Pages | Frame |
|---|---|---|
| Teacher's Guide | 3 | p1 rail + prep, p2 Gospel + questions, p3 lesson outline (tighter padding) |
| Student Handout | 1–2 | rail (hymn, Catechism, prayer, artwork) + Gospel, memory panel, activities |
| Family Take-Home | 2 | no rail; flowing two- and three-column bands |

The craft page borrows the student skeleton and swaps the Gospel column for numbered craft
steps.

## Extending to a new level or class

Change the identity chip and the Level Question. Nothing else. A midweek class or a seasonal
piece is still one of the three skeletons above.
